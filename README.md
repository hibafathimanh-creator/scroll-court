# SCROLL COURT ⚖️
> *“Your attention is on trial.”*

**Scroll Court** is a digital-wellness web platform that treats excessive, unconscious scrolling like a courtroom for human attention. It poses the central philosophical question of modern technology:

> **“Who is in control of your attention — you, or your screen?”**

Designed with an aesthetic of **Apple-level simplicity + modern editorial magazine + futuristic courtroom + premium health-tech**, Scroll Court shuns boring productivity metrics and childish gamification in favor of emotional intelligence, clarity, and sovereignty.

---

## 🏛️ Core Experience & Features

### 1. The Hero Docket
* Dramatic editorial headline: *“YOUR ATTENTION IS ON TRIAL.”*
* Interactive **Animated Scale of Attention**: Live SVG balancing *Conscious Agency* against *Digital Drift*.
* Real-time attention status indicator (*“UNDER YOUR CONTROL”* vs *“DRIFTING DETECTED”*).
* Socratic inquiry: *“You opened your phone for one thing. How many minutes did you actually give it?”*

### 2. The Courtroom Dashboard
* **Evidence Exhibits A through H**:
  1. Total screen time (4h 12m)
  2. Doom-scroll time (1h 47m unintentional scrolling)
  3. Number of pickups (27 pickups)
  4. Longest scrolling session (42m late-night session)
  5. Most distracting app category (Endless Feeds & Short Videos)
  6. Focus time recovered (38m reclaimed)
  7. Current conscious streak (4 days of awareness)
  8. Number of intentional sessions (6 deliberate blocks)
* **Daily Judicial Verdict**: *“Your attention was interrupted 27 times today. You noticed the pattern.”* (Categories: `INTENTIONAL`, `DRIFTING`, `RECOVERING`, `FOCUSED`).
* Exhibit Inspection Modals for each piece of evidence.

### 3. The Scroll Detector
* Identifies 7 behavioral anomalies: Unusually long sessions, rapid app switching, late-night scrolling, repetitive checking, and feed wandering.
* **24-Hour Visual Chronological Timeline**: Interactive timeline showing exact periods of focus, social interaction, and flagged doom scrolling.
* Non-judgmental pattern banner: *“Pattern detected. You appear to have entered a 42-minute unplanned scrolling session.”*
* Compassionate inquiry: *“WHY AM I HERE?”* diagnosing mental fatigue, task avoidance, connection needs, or pure muscle memory.
* **Live Infinite Feed Simulator**: Real-time interactive scroll trap that measures scroll velocity (px/s) and triggers live Court Interruptions.

### 4. Scroll Interruption System (`COURT INTERRUPTION`)
* Non-punitive intervention overlay when continuous scrolling crosses boundaries.
* Prompt: *“You've been scrolling for 30 minutes. Was this intentional?”*
* Choice architecture:
  * `YES — I CHOSE THIS` (logs session as conscious leisure).
  * `NO — I GOT LOST` (empowers the user to reclaim attention).
* Somatic 2-Minute Reset: Guided 4-4-4-4 box breathing pacing circle with crystalline Web Audio chimes.

### 5. Today's Case File (To-Do List + Contextual Interruption)
* Manage daily intentions with priorities (`urgent`, `high`, `normal`) and estimated minutes.
* Launch any case task directly into **Focus Mode**.
* Contextual reminder trigger: *“Your attention has been on social media for 34 minutes. You told yourself you wanted to finish: ‘Study for 1 hour.’”* Options: *Return to Task*, *5 More Minutes*, *I'm Taking a Break*.

### 6. Body Signals & Attention × Body Correlation
* **Real Web Bluetooth API Integration**: Standard Web Bluetooth GATT Heart Rate Service (`0x180D`, characteristic `0x2A37`).
* Clearly labeled `[DEMO DATA - SIMULATED FOR ILLUSTRATION]` fallback when hardware is absent.
* **Real-time Animated ECG Waveform**: HTML5 canvas rendering dynamic P-Q-R-S-T cardiac pulses synchronized to BPM.
* Full scientific & medical transparency disclaimer: *“Your heart-rate pattern changed during this period. Your body changed while your attention stayed online. Correlation does not automatically mean causation.”*
* **Dual-Axis Correlation Graph**: Hour-by-hour comparison of scrolling duration vs heart rate.

### 7. Signature Feature: The Attention Mirror
* Proportional 24-hour spectrum bar (Sleep, Focus, Real Life, Social, Entertainment, Unplanned Scrolling).
* The Mirror Question: *“If your attention were money, would you spend it this way again?”*
* **Attention Currency Simulator**: Interactive slider showing compound life returns (e.g., reclaiming 45 mins/day = 273 hours/year = 11.4 full waking days = 27 books read).

### 8. Digital Detox / Focus Mode (`COURT ORDERS`)
* Customizable binding restraint orders (*“No social media for 30 minutes”*, *“Study until 7:00 PM”*, *“No scrolling during meals”*).
* Fullscreen immersive countdown with circular progress ring.
* Built-in Web Audio ambient brown noise drone synthesizer for deep focus.
* Respectful non-coercive early exit.

### 9. Emergency Scroll Break (`I'M STUCK SCROLLING`)
* Floating action button + header button + keyboard hotkey `E`.
* Suspends feeds immediately.
* 10-second meditative reset countdown.
* Reflective inquiry: *“What did you come here to do?”*

### 10. The Weekly Case
* Macroscopic 7-day audit of total scrolling, intentional ratio, and vulnerability windows.
* 4 Socratic Inquiries with interactive answers auto-saved to on-device storage.

### 11. Full-Screen Reflection Sanctuary
* Cinematic gradual text reveal: *“You don't need more discipline. Sometimes you just need to notice.”*
* Private local reflection journal with observation archive.

### 12. Privacy: “Your Data Is Yours”
* 100% on-device architecture (zero cloud databases, zero tracking pixels, zero analytics).
* Permissions matrix: Web Bluetooth, Web Notifications, Local Storage, Web Audio.
* Export Case Dossier as JSON.
* **“Burn The Evidence”**: One-click wipe of all local data.

## ⌨️ Keyboard Directives & Accessibility

* `1` → The Courtroom Dashboard
* `2` → The Scroll Detector
* `3` → The Attention Mirror
* `4` → Today's Case File
* `5` → Focus Mode / Court Orders
* `E` → Emergency Scroll Break (*“I'm Stuck Scrolling”*)
* `?` → Open Keyboard Directives modal
* `Esc` → Dismiss any modal
* **Accessibility**: Full Reduced Motion mode, High Contrast (WCAG AAA) mode, screen-reader friendly ARIA labels, and responsive mobile bottom dock.

## 🚀 Running Locally

Scroll Court is built with modern ES modules, semantic HTML5, Tailwind CSS, and custom styling. Zero build tools or Node installations required.

```powershell
# Run with Python built-in HTTP server:
python -m http.server 8000

# Open in browser:
http://localhost:8000
```
